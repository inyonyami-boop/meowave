# 项目术语表

> 供后续会话（含迁移到新项目后的 AI）理解本项目习惯用语的指代对象。
> 每个脚本模块头部也有一行术语注释，指向本表。

## 界面与流程

| 用语 | 指代对象 |
|---|---|
| home 界面 / Home | `scripts/Home.lua`：黑色背景 + 带透明窗洞的墙 + 窗内等待/跳出的猫 + 底部“— 新的救援 —”入口文字 |
| — 新的救援 — | home 界面底部跳动闪烁的入口文字，点击后进入 Level 1 |
| Level 1 / 第一关 | `scripts/Level1/Main.lua` + `Level1/Config.lua` 定义的关卡 |
| 控制台 | `scripts/Global/ConsoleUI.lua`：底部机台，含红/绿按钮、猫脸计数、右侧工具凹槽；开场从屏幕下缘升起并伴随分层震动 |
| 教程 | `scripts/Global/Tutorial.lua`：进入关卡后先暗化画面、引导员入场、对话框逐字显示文案 |
| 结算 / 结局 | `scripts/Global/LevelResult.lua`：胜利或失败后的动画阶段 |

| 用语 | 指代对象 |

| 对话框 | 教程文本气泡，`Global/Images/Dialogue.png` |

## 文案文件与标记

| 用语 | 指代对象 |
|---|---|
| level_1 / 教程文案 | `Level1/Text/level_1.txt`（原稿在 `docs/level_1.txt`） |

## 数值口径

| 用语 | 含义 |
|---|---|
| 已拦截 | 控制台绿猫脸旁数字；栅栏碰撞与救猫人接住都会累加（同一只猫可能计两次） |
| 已漏过 | 控制台红猫脸旁数字；落地或离场未接住计一次 |
| resolved | 内部计数：每只猫最终接住或落地只计一次，用于 Level 1 的 6 只结束条件 |
| 失败判定 | 已漏过 > 关卡编号（Level 1 为漏过 ≥2 立即失败） |
